AR SOUND SLIDER — ต้นแบบคำ CAT
================================

โปรแกรมที่ใช้
1. Visual Studio Code (VS Code) — เขียน/แก้ไขไฟล์ HTML, CSS, JavaScript
2. Google Chrome หรือ Microsoft Edge — เปิดและทดสอบเว็บ
3. MindAR Image Target Compiler — สร้างไฟล์เป้าหมาย .mind จากภาพบัตรคำ
4. GitHub Pages หรือ Netlify — เผยแพร่เว็บให้เปิดผ่าน HTTPS บนมือถือ
5. Canva หรือ PowerPoint — ออกแบบภาพบัตรคำ CAT (ทางเลือก)

ไฟล์ในโครงการ
- index.html: โครงสร้างหน้าเว็บและฉาก AR
- style.css: สี รูปแบบปุ่ม และการจัดวาง
- app.js: ปุ่มเสียง ตัวเลื่อน และการแสดงภาพเฉลย
- targets/cat.mind: ต้องสร้างเองจากภาพบัตรคำก่อนใช้ AR
- assets/audio/c.mp3, a.mp3, t.mp3: ใส่ไฟล์เสียง phoneme ที่บันทึกหรือจัดทำไว้

เริ่มทดสอบหน้าจอ (ยังไม่สแกน AR)
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ AR_Sound_Slider_CAT ใน VS Code
3. ติดตั้งส่วนขยาย Live Server (โดย Ritwick Dey) ใน VS Code
4. คลิกขวาที่ index.html แล้วเลือก Open with Live Server
5. ทดสอบปุ่มและตัวเลื่อนบนคอมพิวเตอร์

ทำให้สแกนบัตรคำได้
1. ออกแบบบัตรคำ CAT ที่มีลวดลายชัดเจนและไม่เรียบเกินไป
2. บันทึกภาพเป็น cat-card.jpg
3. เปิด MindAR Image Target Compiler (ค้นคำว่า MindAR Image Target Compiler)
4. อัปโหลด cat-card.jpg และสร้าง/ดาวน์โหลดไฟล์เป้าหมาย
5. เปลี่ยนชื่อไฟล์ผลลัพธ์เป็น cat.mind
6. นำไฟล์ไปวางในโฟลเดอร์ targets/cat.mind
7. ทดสอบผ่านเว็บที่เผยแพร่ด้วย HTTPS แล้วเปิดจากโทรศัพท์ อนุญาตการใช้กล้อง และส่องบัตรคำ

ข้อควรทราบ
- ไฟล์ targets/cat.mind ไม่ได้รวมมา เพราะต้องสร้างจากภาพบัตรคำจริงของผู้ใช้
- เสียง MP3 ไม่ได้รวมมา ให้เพิ่มไฟล์เสียง phoneme ที่ถูกต้องเองใน assets/audio
- หากยังไม่มี MP3 ระบบจะลองใช้เสียงสังเคราะห์ของเบราว์เซอร์ ซึ่งไม่เหมาะใช้เป็นเสียงสอน phonics จริง
- ต้องใช้ HTTPS หรือ localhost เพื่อให้เบราว์เซอร์อนุญาตกล้อง
- ต้นแบบนี้เป็นจุดเริ่มต้นเพื่อทดสอบการทำงาน ไม่ใช่ระบบประเมินอัตโนมัติที่เชื่อถือได้
- ครูควรฟังนักเรียนอ่านคำจริงและใช้เกณฑ์ประเมินรายบุคคล
